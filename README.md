# Hoard

**Pre-alpha. Not ready for production use.**

Self-hosted cloud sync for game save files. Store your saves on your own server,
sync across machines, keep a full version history with instant restore.

Built with Rust (Axum + SQLite). Clients for Linux and Windows.

## Status

Currently in active development. See the build guide for the roadmap.
